## Summary

> This room focuses on exploiting a misconfigured PostgreSQL instance exposed on port 5432. The attack chain involves bruteforcing default PostgreSQL credentials using Metasploit, reading sensitive system files via the `COPY FROM` technique, harvesting credentials from a web application config file, and escalating to root via `sudo ALL` privileges.

## Lessons Learned

#### 🔴 Côté Attaquant (Offensive)

- **PostgreSQL exposé sur le réseau** → toujours tester les credentials par défaut (`postgres:postgres`, `postgres:password`) — les modules MSF automatisent ça très vite.
- **`COPY FROM` / `postgres_readfile`** → une DB compromise = potentiel accès au filesystem entier si le service tourne avec des permissions élevées.
- **Credential reuse & config files** → les fichiers `config.php` world-readable sont une mine d'or. Réflexe : `find / -name "*.php" -perm -o+r 2>/dev/null` après accès initial.
- **Lateral movement via credentials** → `dark` n'avait pas de sudo, mais le mouvement latéral vers `alison` via config.php a débloqué l'escalade complète.

---

#### 🔵 Côté Défenseur (Defensive / Blue Team)

- Ne jamais exposer PostgreSQL (port 5432) directement sur le réseau — firewall ou bind sur `127.0.0.1` uniquement.
- Changer les credentials par défaut du compte `postgres`.
- Les fichiers de config web ne doivent **jamais** être en `777` — principe du moindre privilège.
- `sudo ALL` accordé à un user standard = Game Over immédiat si ce compte est compromis.

## Attack Chain Summary

```
Nmap → PostgreSQL 5432 exposé (misconfiguration)
    └── MSF postgres_login → postgres:password
            └── postgres_readfile /etc/passwd → users: dark, alison
            └── postgres_readfile /home/dark/credentials.txt → dark:qwerty1234#!hackme
                    └── SSH dark@target
                            └── /var/www/html/config.php (world-readable)
                                    └── alison:p4ssw0rdS3cur3!#
                                            └── SSH alison@target
                                                    └── sudo ALL → root
```
