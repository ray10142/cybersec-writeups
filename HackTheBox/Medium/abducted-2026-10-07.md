## Summary

This box chains a Samba print-subsystem command injection into full host-root
via credential reuse and a polkit/systemd misconfiguration. The print job name
is passed to the configured `print command` unescaped (RCE as the print
account). An `rclone` backup config yields an obscured — not encrypted —
password that is reused by a local user. A second Samba share with `force user`
+ `wide links` allows writing an SSH key into another user's home. That user is
in a group granted systemd control via polkit, exploited through a service
drop-in that runs as root.

## Exploitation

### Foothold — Samba print command injection (→ `nobody`)
Samba substitutes the print **job name** into the configured `print command`

print service account.

## Privilege Escalation

### polkit + systemd drop-in (`marcus` → `root`)
- `marcus` is in group **`operators`**.
- polkit rules grant `operators` systemd actions without authentication:
  `org.freedesktop.systemd1.reload-daemon` + `org.freedesktop.systemd1.manage-units`.
- Writable drop-in directory: `/etc/systemd/system/smbd.service.d/`.
```
# /etc/systemd/system/smbd.service.d/root.conf
[Service]
ExecStartPre=[REDACTED — root payload]
```
```
systemctl daemon-reload
systemctl restart smbd.service
systemctl status smbd          # verify start (unit has ExecCondition=)
/bin/bash -p
id                             # euid=0(root)
cat /root/root.txt             # -> HTB{REDACTED}
```
**Gotcha:** the smbd unit carries `ExecCondition=`. If it exits non-zero,
systemd skips start and `ExecStartPre` never runs — check `systemctl status`.

## Lessons Learned

### 🔴 Côté Attaquant (Offensive)
- Samba `print command` + job-name non échappé = RCE classique (CWE-78).
  Réflexe : tester l'injection via le *nom* du fichier, pas son contenu.
- rclone `reveal` = tout mot de passe dans un `.conf` rclone est en clair pour
  l'attaquant. Chercher les configs de backup après accès initial.
- Réutilisation de credentials → tester chaque mot de passe récupéré contre
  tous les users à shell (`grep 'sh$' /etc/passwd`).
- `wide links = yes` + `force user` → écriture d'`authorized_keys` hors du
  partage prévu.
- `id` / `groups` après chaque pivot : un groupe non standard = la piste privesc.

### 🔵 Côté Défenseur (Defensive / Blue Team)
- Échapper les entrées utilisateur dans `print command`, ou désactiver le
  print spooler Samba si inutile.
- Ne jamais stocker de secrets rclone sur un hôte accessible ; secrets manager
  + interdiction de réutilisation service/SSH.
- `wide links = yes` avec `unix extensions = no` = traversée de chemin ;
  à auditer avec `force user`.
- Restreindre les règles polkit : déléguer tout `org.freedesktop.systemd1.*`
  à un groupe = chemin direct vers root.
- Alerter sur `smbclient -L` anonyme réussi et sur les process enfants
  inattendus du compte de service Samba/print.
